# Class Compass

School management system for Kenyan schools: CBC, 8-4-4, British and college curricula, M-Pesa (Daraja) and Paystack fee payments, and parent, learner and staff portals.

- `api/` — Laravel 11 API, the product website and the admin web pages
- `web-app/` — Flutter app (web, Android, iOS) for schools, parents, learners and staff
- `brand/` — logos, icons and banners

Setup: see [CLASS-COMPASS-SETUP.md](CLASS-COMPASS-SETUP.md). Go-live checklist: [PRODUCTION-READINESS.md](PRODUCTION-READINESS.md).
